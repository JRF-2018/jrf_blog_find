ココログや Movable Type のシステムと奮戦中

MTEntries では sort_by と last_n を同時に使うことができず、 MTArchiveList では offset を使うことができないようだ。

また、XML-RPC で更新情報として TIMESTAMP を書き込んだとき、月をまたぐと、(週別の)個別アーカイブの位置が変わるため、Permalink が変更されてしまうようだ。

やろうとしてることは、まず、しかたないので XML-RPC では TIMESTAMP の更新をせず、その代わりに記事を default のソートではなく、 sort_by="modified_on" にして、さらにそこから最新の 5 個ぐらいとって《記事の属するカテゴリ内の最近の記事》を表示しようということである。

これは、sort_by と last_n を同時に使えないことからできないようだ。

さらに、こちら(日)とこちら(US)を参考に Google サイトマップを導入しようとしているが、ページの changefreq を今週分のアーカイブのみ daily としたい。

これは MTArchiveList で offset が使えないため素直にはできない。とりあえず、今週分のみ重複させてマップを作ったが、Google はどう判断するんだろう……。

また、各サブブログで別々にサイトマップを作ったあと SSI で Sitemap Index を作ろうとしているが、.xml は SSI されないようなので .html にした。(さらに .xml は .inc と同じようにファイルとして表示されない。)これまたGoogle はどう判断するのだろう……。

とりあえず、ココログではできないと思っていた MovableType の MTEntryModifiedDate が、TypePad 系では MTEntryDateModified でできることがわかっただけでも収穫としておこう。

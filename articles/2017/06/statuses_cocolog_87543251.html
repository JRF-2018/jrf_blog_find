quail-naggy.el と jrf_semaphore.pl…

quail-naggy.el と jrf_semaphore.pl をアップデートした。バグ取りのみ… naggy-backend.pl の単漢字変換で a とか i とかがうまくいかなかったことの修正など。
JRF 2017年6月8日

《quail-naggy.el: 単漢字変換 Input Method for Emacs.》
http://jrf.cocolog-nifty.com/software/2015/10/post.html

《JRF Flag Semaphore for NES Emulator を作った》
http://jrf.cocolog-nifty.com/software/2014/03/post-1.html

quail-naggy.el のほうは、バージョン 0.08 に、jrf_semaphore.pl のほうは、バージョン 0.09 になった。

JRF 2017年6月8日

……。

quail-naggy.el については、まず、Naggy::TankanjiDic を変更。場合により日本語読み(い や まん)を英語読み(i や man)より優先度を高くした。tankanji.txt や Wind2.txt などの辞書をいじるのを嫌って、アルゴリズムを複雑にしたが、よくない方策を取ってしまったかもしれない。

また、quail-naggy.el において変換時 backspace が naggy-convert-prev-page に割り当たっていなかったのを修正。

JRF 2017年6月8日

……。

jrf_semaphore.pl については変更は基本的にはない。…のだが、上の Naggy::TankanjiDic をいじった影響が出る場合もある。ほぼ影響はないものと思われるが…。

とはいえ、前回([cocolog:87451120])の更新が jrf_semaphore.pl に関しては割と意味のある変更だったのにバージョンナンバーを上げなかったので、そのかわりに、今回は、意義の少ない変更でも、バージョンナンバーを 0.09 に上げることにした。

JRF 2017年6月8日

……。

テストは正直、あまりしていない。ただ、quail-naggy.el はしばらく使ってみてからのリリース。前(々)回よりはマシなはず。

JRF 2017年6月8日

ミニスーファミ『ゼルダの伝説…

ミニスーファミ『ゼルダの伝説 神々のトライフォース』をクリア。「どこでもセーブ」とネットの攻略情報があれば誰でも解ける感じ。それがない時代、ほんとに解けたのか疑うほど。私も初代ゼルダとかムジュラの仮面は、ほとんど攻略情報なしで解いたけど…。
JRF 2017年10月25日

(前回のミニスーファミに関する「ひとこと」は、[cocolog:88289468]。)

JRF 2017年10月25日

……。

『ゼルダの伝説』シリーズは、初代を楽しんでクリアしたことをよく覚えている。『リンクの冒険』もやったはずだが、こちらはよく覚えていない、クリアしたかも定かではない。NINTENDO64 で『ムジュラの仮面』はたしかやってクリアしたはずだが、『時のオカリナ』はどうだったか、リンクで馬に乗った覚えはあるのだが…。

最近では、2013年に、[cocolog:75770207] で GBC(3DS VC)『ゼルダの伝説 夢を見る島DX』をクリアしたことはチョコっと書いた。このときも「どこでもセーブ」のお世話になったが、今回ほど多用はしなかった気がする。

JRF 2017年10月25日

今回は攻略情報を見ながら、ダンジョンでは一部屋ごとに「どこでもセーブ」をするぐらいの感じで進めた。

攻略情報は、↓を頼り、ときたま他のサイトをググった。

《nJOY：ゼルダの伝説 神々のトライフォースの攻略》
http://i-njoy.net/zd3_top.html

nJOY はミニスーファミのゲームの攻略でこのところ毎度お世話になっている。

JRF 2017年10月25日

……。

私は攻略情報を見るからいいのだが、情報がない時代はどうしていたのだろうと心配になった。スーファミの時代、攻略情報なしに解ける人間がいただろうか？

JRF 2017年10月25日

オカリナが埋まっている位置とか、ヒントなさ過ぎだろう。花の種と共に埋めたということだけど、花の咲いてるところなんて無数にある。同じ動物の園で見つかるからいいものの、シャベルはどこでも使えるから、あやしいところをずっと探すことになりかねない。少なくとも動物の園は全部堀るぐらいは期待されていたのだろうか？

JRF 2017年10月25日

また、「MP消費量1/2」では、鍋に「魔法の粉」をかけるというのも攻略情報なしでは気付けるようには思えない。

JRF 2017年10月25日

最初クリアするときは、攻略情報を見て、素直にアイテムを取ったんだけど、「これどうやって気付けばいいんだろう？」とあとで気になった。闇の世界では話す木があるという情報をあとで知って、それを確認していったがそれらしい話は聴けなかった。「占い屋」というものがあるが、それで聴けるのか…。

JRF 2017年10月25日

気になって、クリア後、もう一度、闇の神殿までプレイしなおすという面倒くさいことをして、ゲーム内の情報がないか確かめた。「どこでもセーブ」は一つのゲームにつき四つしかできないので、以前のセーブなんて残ってないので、もう一度最初からやり直したのだった。

JRF 2017年10月25日

シャベルを取ったあとや、鍛冶屋の井戸に飛び込んだあとで「占い屋」に行ってみたが、目ぼしい情報は得られなかった。

JRF 2017年10月25日

ほんと、どうやって気付いたんだろう？ シラミつぶしに試した人がいて、その人の情報が広まったんだろうか？

JRF 2017年10月25日

……。

ボス戦は大変だが、攻略情報のおかげでビンもハートも多めに所持している上に、どこでもセーブでいいところからやり直せるとあって、難易度はかなり甘めになる。

ダンジョンの仕掛けも普通にやれば、ハートや魔法を消費しまくるようなところも最低限のコストでクリアしたデータをどこでもセーブでつなげていけばいい。ありがたい。

ただ、「自分で解いた」という充実感はない。一応、途中までは攻略情報は見ずにやってみて必要なところだけ見ることにしていたのだが、最後のほうは、最初から攻略情報に頼った。おもしろさ半減かもしれないが、何時間も悩むよりは易きに流れてしまった。

JRF 2017年10月25日

……。

『ゼルダの伝説』シリーズはおもしろいね。でも、ストーリーに深みがあるとは少し言いにくいから、物語の魅力というよりは、新聞等のパズルを飽きもせず楽しみにするのに似ているのかもしれない。

またゼルダやりたい…。3DS でいろいろ出てるからそれを求めてもいいかも…。けど、今しばらくはシンドイから遠慮しとくわ…。

JRF 2017年10月25日

……。

……。

ミニスーファミ、他のゲームもチョコっとやってみてる。

JRF 2017年10月25日

『超魔界村』。最初のステージで死にまくって、とても解けるような気がしないんですけど…。[cocolog:75973322] で初代『魔界村』を解き、確か、ファミコン版も 3DS VC で解いたはずだけど、この『超魔界村』はそれより難しそうで、やる気が続かない…。

JRF 2017年10月25日

『パネルでポン』略して『パネポン』。私が好きなゲームでスーファミでもやったし GBC『ポケモンでパネポン』もやった。が、久々にやってみて、すごい下手になってる。ステージクリアで最後までいかないとか、どうしたの → 私。昔は Hard をクリアして Very Hard にも挑戦していたと記憶しているのに、あれは記憶違いなのか？ ってほど下手になってる。連鎖を組むスピードが出ない。

JRF 2017年10月25日

『スーパーストリートファイターII』。XBOX で『スーパーストリートファイターII X』の激ムズに挑戦していた身からすると CPU が強くない。楽々クリアできる。昔はジョイスティック専門…的なところがあったが、3DS の『スーパーストリートファイター IV』でパッド操作だったし、いろんな場面でパッド操作のこともあったから、連続技は出にくいけど、昇龍拳コマンドぐらいなら余裕で出せる。でも、このゲームは対戦してなんぼだからなぁ…。

JRF 2017年10月25日

ミニスーファミ、もう値段分、元はとった感じかな。よく遊んだ。次は FF6 かカービィか…。もう、しまっちゃうのもアリだけど…。

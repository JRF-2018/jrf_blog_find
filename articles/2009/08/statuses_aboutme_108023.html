Windows Update…

Windows Update を二つ起ち上げたら、ダメだよな。一個起動したあと、追加情報が気になってもう一個起ち上げ、そしたら二個目のほうに軽い更新が表示されたので先にそれを入れた。その後一個目の更新をしようとすると「パラメータが違う」みたいなエラーが出た。
JRF 2009年8月26日

ハマっていろいろヘルプで提案されたソフト等を使ってみたが、エラーは変わらない。

おそらく二個起ち上げたのがいけなかったと思い、Windows の修復をそれらの Update の前のもので行って、再度一個の Updater で順にやり直したところうまく行った。

ちなみに、うまくアップデートできずエラーが出た「重い」更新は Vista の SP2 (Service Pack 2)。はじめは、SP2 特有のバグかと思って、ヘルプの感想にもそう書いてしまった。…恥ずかしい。ヘルプの感想書き直したい。
JRF 2009年8月26日

エラーはたしか↓だった。
0x80070057 	 ERROR_INVALID_PARAMETER 	 パラメータが間違っています。
JRF 2009年8月26日

Windows の「修復」じゃなくて「復元」というべきか。

Vista の「復元」は「バックアップと復元」という大変似た名前の別ものがありまぎらわしい。「コントロールパネル→システムとメンテナンス→バックアップと復元センター」の右ではなく *左* のタスクにある「システムの復元を使って Windows を修復」を使う。

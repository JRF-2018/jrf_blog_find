Perl の include…

Perl の include って何でこんなに難しいんだ。自動生成したファイルをちょっと取り込むだけでエラい苦労。include じゃなく do "file" で取り込むんだけど、そのファイルの中でも use utf8 しないといけないとかヒドい。
JRF 2009年9月4日

use utf8 するから 呪文のように use warnings と use strict やったら、モジュールに関するエラーが出やがる。あとで C で書くつもりだから、オブジェクト指向を使いたくないときにこの重荷は辛い。

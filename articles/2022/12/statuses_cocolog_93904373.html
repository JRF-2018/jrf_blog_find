VRChat、Avatar…

VRChat、Avatar のアップロードを試してみた。いろいろ引っかかりはしたものの、軽量化したモデルのアップロードは簡単にできた。しかし、Quest (Android) 用のモデルまでは作れなかった。
JRF 2022年12月13日

まず、↓を参考に…。

《VroidをVRChatへアップロードするまとめ》  
https://rekor64y.web.fc2.com/

最初に、Unity Hub をインストールするところでつまづく。理由は Visual Studio をインストールしていなかったから。私、プログラミングは基本 Emacs と Cygwin を使っていて、Visual Studio はできるだけ入れないでおこうとしてたんだよね。が、しかたがない。

JRF 2022年12月13日

なお、Visual Studio Community では Unity のモジュールもインストールする必要があるが、右のペーンで Unity Hub のチェックは外す。

それを入れたあとは、↑を元に、Unity の適当なバージョンもインストールが成功した。VRChat のアップロードまではそのまま進み、VRChat でアバターを表示できた！ いちおう。…というのは、品質が Very Poor で↓によると、モデルを軽くする必要があるらしいから。

JRF 2022年12月13日

《VRoid Studioで作ったモデルをVRChatに上げてVRで動かしてみたメモ | 神部まゆみのブログ》  
https://knb-mayumi.com/vroid-vrchat/

《VRoidStudioで作ったモデルのボーンをblenderで削減してみたメモ | 神部まゆみのブログ》  
https://knb-mayumi.com/vroid-boan-sakugen/

JRF 2022年12月13日

VRoid Studio のエクスポートでいろいろモデルを軽くするのも試してみる。3つほど試して、結局、Poor のモデルと、Medium のモデルと Good のモデルがアップロードできた。

JRF 2022年12月13日

……。

Good のモデルは Quest (Android) にも使えるんじゃないか…と思って、VRChat SDK で  Switch Build Target to Android にしようとしたら、なんか、モデル評価の部分をみると Switch できてる感じなのに全体として切り換わっている感じじゃなく、今度は Build Target to Windows に切り換えられなくなってしまった。

JRF 2022年12月13日

ググって↓の記事を発見。

《Can't switch target build to android : VRchat》  
https://www.reddit.com/r/VRchat/comments/lxv484/cant_switch_target_build_to_android/

JRF 2022年12月13日

Unity の File → build setting から、Android 用のをインストールするように Unity Hub へ指示を出し、それはうまくいかなかったのだけど、Unity Hub で Android のモジュールもインストールしたことで、解決した。

で、結局、ポリゴン数もボーンなども Quest の条件に合わないと言われて、Quest 用のアップロードはできなかった。blender でいじれば可能性はあるのかもしれないが、今のところ私は blender まで使うつもりはない。

JRF 2022年12月13日

Fallback は Windows 用で Good ならできるのでは…と当初、解釈していたのだが、それではダメで、Quest 用で Good を出すモデルがないとダメらしい。

JRF 2022年12月13日

……。

このメンドクサさを考えると cluster.mu はエラい楽だった。VRChat は私みたいなマシンパワーの少ない＆技術力のない(＆コミュ障の)人間にはハードルが高い。

まぁ、とにかく、できた Avatar で世界を周るのはまた今度…。

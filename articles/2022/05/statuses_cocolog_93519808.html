JRF 2022年5月28日

私は「マイナンバー」は本来は、背後に非公開の ID があって表示属性違いの複数 ID 同時取得可能にすべきだったと考えている (参: [cocolog:92605977] とか)。何なら一度やめて再設計するべきだ。

保険証も顔写真などの表示がない複数 ID の典型的な一つとすれば良かった。医療過誤がないように顔写真を付す…というのは逆に医療過誤につながると思うんだよね。顔写真って結構あやふやだから、そうでない部分でちゃんと確かめたほうがいい。

JRF 2022年5月28日

[cocolog:93208056] の胚の遺伝子情報は、各医院または地域拠点がそれぞれ保存するアイデアと同じように、各医院にあるものを転送してもらうしかなく、そのネットを充実させるのが重要で、マイナンバーで一括管理というのはプライバシーの観点からやめたほうがいいと思うんだよね。

JRF 2022年5月28日

まず、個人を特定できそうな属性に関して query をかけてそれで上がってきたデータに関して、保険用 ID で検索するというのがプライバシー的にベターだと思う。それで一致しない場合のみ、保険用 ID で全検索できるようにする。どこかの悪意ある医院が、保険用 ID に結び付けられた個人特定属性をネコソギ得ることがないように。

JRF 2022年5月28日

上の記事で「健康保険払ってない人が他人のを借りられない」…ともあるが、逃亡したり何か罪を犯したからといって、命を奪うまでのことをしてはいけない…というのがまずある。

できれば、わずかな「違法利用」には目をつぶったほうがいい。それが日本の雅量を示すことになると思う。

そういうことで恨みを買うことのリスクはかなり大きいのではないか。効率に表せない大きな効用がある気がする。

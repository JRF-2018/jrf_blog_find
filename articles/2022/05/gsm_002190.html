jrf> マイナンバーと健康保険証。マイナンバーさえあれば緊急入院の際などに役立つとか意見があるが、今のマイナンバーの「効果」を考えれば疑問だ。

《どうしてマイナンバーカードと健康保険証とお薬手帳を合体させないといけないのか | アゴラ 言論プラットフォーム》  
https://agora-web.jp/archives/220526101958.html

私はマイナンバーは背後に非公開の ID があって表示属性違いの複数 ID 同時取得可能にすべきだと考えている (参: [cocolog:92605977] とか)。

保険証も顔写真などの表示がない複数 ID の典型的な一つとすれば良かった。医療過誤がないように顔写真を付す…というのは逆に医療過誤につながると思うんだよね。顔写真って結構あやふやだから、そうでない部分でちゃんと確かめたほうがいい。

[cocolog:93208056] の胚の遺伝子情報は、各医院または地域拠点がそれぞれ保存するのと同じように各医院にあるものを転送してもらうしかなく、そのネットを充実させるのが重要で、マイナンバーで一括管理というのはプライバシーの観点からやめたほうがいいと思うんだよね。

まず、個人を特定できそうな属性に関して query をかけてそれで上がってきたデータに関して、保険用 ID で検索するというのがプライバシー的にベターだと思う。それで一致しない場合のみ、保険用 ID で全検索できるようにする。どこかの悪意ある医院が、保険用 ID に結び付けられた個人特定属性をネコソギ得ることがないように。

上の記事で「健康保険払ってない人が他人のを借りられない」…とあるが、逃亡したり何か罪を犯したからといって、命を奪うまでのことをしてはいけない…というのがまずある。

できれば、わずかな「違法利用」には目をつぶったほうがいい。それが日本の雅量を示すことになると思う。

そこで恨みを買うことのリスクはかなり大きいのではないか。効率に表せない大きな効用がある気がする。

高額医療が増えて、予算が厳しいというのはあるかもしれないが、保険を二段立てにするなど、何か別の方法がないかと私は思う。

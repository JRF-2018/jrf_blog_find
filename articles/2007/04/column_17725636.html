前期の翌日(2007-01-01)から昨日(2007-03-31)まで 90 日間のアクセス解析と近況報告

今期 2007-01-01 から 2007-03-31 までの 90 日間のアクセス解析をします。本格運用開始(2006-01-28)からは 428 日たっています。なお、前期は 2006-10-01 から 2006-12-31 までの 92 日間でした。

今期の報告では前期と同じようなものと、ページごとの大まかな解析および、はてなブックマークに関するデータの公開を行います。今回ももちろん、具体的な検索ワード等来訪者のプライバシーに関する情報は開示しません。

現在このサイトには４つのブログがあります。それらはほぼ同時に本格運用をはじめました。ココログアカウントの取得やブログの作成はそれより以前からはじめたので、表示される平均アクセス数はあまりあてになりません。自分で計算機で出してます。

今回は、初回からの累計と前期の次の日(2006-01-01)からの累計を表示します。

■ココログのアクセス数
  
なお、純コメ、純トラバは自分自身のものとスパムを除いたコメント、トラックバックの数です。記事数を考えるとコメントもトラバもないに等しいです。

  ブログ累計            累計  1日平均 記事数 純コメ 純トラバ 
  《雑記》              36128 84.4    133    6      9        
  《宗教と動機付け》    6226  14.5    32     3      1        
  《税・経済・法》      2961  6.92    19     0      3        
  《ソフトウェア Tips》 12057 28.2    27     0      5        
  計                    57372 134.0   211    9      18       
  ブログ増分            累計  1日平均 記事数 純コメ 純トラバ 
  《雑記》              8067  89.6    3      0      0        
  《宗教と動機付け》    1752  19.5    0      0      0        
  《税・経済・法》      930   10.3    1      0      1        
  《ソフトウェア Tips》 3272  36.3    0      0      2        
  計                    14021 155.8   4      0      3        

  
かなり自分のアクセスが含まれていると思います。やや多めに見つもると記事数×3 + 日数ぐらいでしょうか？そうすると増分の方では平均 154.7 アクセスになります。前期はそれが 137.7 アクセスで、増分はこれまでより大きいです。

記事をほとんど登稿していないのにもかかわらず、一月は一時アクセスが増え、それが増分を押し上げています。なぜかはわかりません。

３月下旬になって海外からと思われるコメントスパム、トラックバックスパムが来るようになりました。実はメールでも意外なアドレス宛にスパムが来るようになったり……。「春」ってことなのでしょうか？

■ページごとの訪問者数の解析
  
ココログのページごとのアクセス解析ではアクセス数と訪問者数が表示されます。アクセス数には読んだあと戻ってきた人のアクセス等が含まれるので、訪問者数のほうが実体を表していると思われます。よって、ここからは訪問者数について解析したいと思います。

過去 30 日のブログの全ページの訪問者総数は 3706 です。もっとも上位にくるのがこの Winny の記事で、訪問者数が 445 です。次に《雑記》のトップページがきて訪問者数 301 です。前回訪問者数 758 でトップだったフィギュア写真のカテゴリは訪問者数 119 で五位になりました。訪問者数が 50 を超える記事はトップページやカテゴリページなども含めて 14 ページです。その 14 ページ(6.5%ぐらい)で訪問者数が 1823 (49.2%) になります。前回にくらべるとなだらかになりましたが、新記事の訪問者数が多くなるということもなく、相変わらずひどいロングテールモデルになっています。

前から気にしているのがフィギュア写真へのアクセスの多さです。フィギュア写真が貼られている記事は全部で 41 あります。全ブログ記事に対して2割弱の量です。訪問者数はカテゴリページに 119、個別ページに総計 658、そして《雑記》のトップページもおそらく写真目的で 301、すべて足すと 1078 (29.1%) となります。

前回はフィギュア写真のカテゴリがもっともアクセスがあったのですが、 Googleのキャッシュで上位にこなくなったのか、カテゴリのページへのアクセスは激減しました。変わりに個別ページや週別ページがヒットしやすくなったのかもしれません。この Winny の記事は今だに読まれていますが、以前と変わらず、それ以外の Winny や P2P の記事は読まれていません。

■はてなブックマーク
  
2006年3月31日からはてなで《公開ブックマーク》を付けています。独自のポリシーを持ってブックマークするごとにはてなポイントを送っています。

下表はそのデータです。なお、「ブクマ数」はブックマークした個数、「ポ済数」はポイントを送ったことでブックマークに「ポイント済」とタグしたものの個数、「総送ポ」は送ったポイントの期間計です。「総送ポ」にはてなの手数料は含みません。なお「ポイント済」のタグは忘れていることがありえます。

  期間     ブクマ数 ポ済数 総送ポ 
  今期     125      31     915    
  前期     143      11     400    
  それ以前 417      25     1220   
  計       685      67     2535   

  
「それ以前」および「計」の「ブクマ数」にはセルクマ(セルフブックマーク) が 4 含まれています。

■定期的な読者
  
このサイトはまったく定期的な読者を獲得できておらず、はてなブックマークもほとんどされないのはあい変わらずです。

■近況
  
実は二月から体調がすぐれず、そうこうしていると自覚症状はないのですが、母にいわせると雰囲気がおかしかったそうで、医師から「客観的には(精神分裂病または統合失調感情障害)の再発と思われる」とのようなことを言われました。

入院は前回同様しなくていいのですが、少しリスパダールを増やすなどしていただきました。一時副作用のようなものも見られたので、私にとっては初めての薬である2mgセルシン錠を処方していただきました。

普段から活動は少ないですが、特にこの二ヶ月はできるだけストレスのかからない生活をこころがけていました。

それで「また入院か……」と強く思ったわけでもないですが、おそらく不安感がたかまり、３月中旬に大学時代のサークルの先輩と後輩に連絡し、このサイトの紹介をしたりしました。(アクセス数にはほとんど影響がなかったです。)

今期も、悲しいかな、この記事を読んでくださる方は非常にマレなかただと断言できます。一見さんももちろん歓迎ですが、いつもお付き合いくださる方には、さらに感謝しております。(…と前期からのコピペですみません。)

これからもよろしくお願いします。

Microsoft にまたヤられた。Windows Update 20H2…

jrf> Microsoft にまたヤられた。Windows Update 20H2 が父の古いほうのパソコン(NEC Mate ME-C)で失敗。古いパソコンだから寿命だというのはわかるのだが、前回の Update はうまく当たったので油断してた。

設定の Windows Update の画面を出して、明示的な指示を出して 20H2 のアップデート。何度も失敗してるから暇があるときにできるよう明示的な指示を必要とするように設定してある。この画面でのアップデートもものスゴイ時間がかかる。

そして、再起動。ここでもものスゴイ時間がかかって、しかし、目を離してる隙に再起動は成功したようだ。

しかし、すごい重さ。タスクマネージャーがそもそもプロセスを表示せずおかしいのだが、それでも見ているとディスクまわりが 100% をきらず、遅い。Firefox でググろうとしただけで反応はあるが、検索画面に行かない。ローカルのサーバーにもアクセスできない。

しかたなく、再起動。ここから本当の苦しみがはじまる。起動後、ログイン画面は出て、デスクトップ背景とアイコンの表示までいったところで、ブラックアウト。黒い画面になる。ただし、マウスカーソルは出ていて、Ctrl + Alt + Del の画面は出る。しかし、そこでタスクマネージャーを指定しても起動しない。ウィンドウが一切出て来ない。

↓の手順を辿る。

《黒い画面または空白画面エラーのトラブルシューティング》  
https://support.microsoft.com/ja-jp/sbs/windows/%e9%bb%92%e3%81%84%e7%94%bb%e9%9d%a2%e3%81%be%e3%81%9f%e3%81%af%e7%a9%ba%e7%99%bd%e7%94%bb%e9%9d%a2%e3%82%a8%e3%83%a9%e3%83%bc%e3%81%ae%e3%83%88%e3%83%a9%e3%83%96%e3%83%ab%e3%82%b7%e3%83%a5%e3%83%bc%e3%83%86%e3%82%a3%e3%83%b3%e3%82%b0-79bcd941-5c32-5da9-9a99-9ed1a53b0d94?ui=ja-JP&rs=ja-JP&ad=JP

手順1。Windows キー + Ctrl + Shift + B は効いてる様子がない。

手順2。さっき書いたようにタスクマネージャーを選択してもウィンドウが出てこない。

手順3。セーフモードにして、まず、タスクバーの検索ボックスが機能してない。別のマシンでググってなんとかデバイスマネージャーを起動。その後、ディスプレイアダプターのプロパティをみると、「ドライバーを元に戻す」は選択できないようになっている。

手順4。ディスプレイ アダプターのデバイスドライバーをアンインストール。これを削るのはとても悪い予感がするがやってみる。NVIDIA のドライバが消え、Windows の基本のディスプレイドライバが変わりに入った。解像度は下がったが、結局同じ。

手順5。ウィルスバスターをアンインストール。設定→アプリからはセーフモードだと削除できないとかぬかしやがるので、ネット接続可のセーフモードにして、トレンドマイクロからアンインストールツールをダウンロードして、アンインストール。しかし、変わらず。

手順6。システムの復元は利用できない。何度も利用できるように設定したはずなのに、アップデートごとにそれがなくなり、そして今利用できない。

手順7。設定→ Windows Update をすると、「問題が発生しました。もう一度…」みたいなことを言われる。

ここで DISM.exe と sfc /scannow も試す。

今時間をかけてそれを試しているところ。すっかり徹夜。ちょっと寝る。

jrf> マイナ保険証なんて百害あって一利なしだよ。保険証は家族には貸すもので、一方、運転免許証は常に携帯しなければならない。両者を統合すると免許証不携帯が増えるだけ([cocolog:93791363])。結局、カードは分けて複数カードを可にし、裏で隠れた ID で統合すれば十分。

隠れた ID に反感があってマイナンバーにしたのかもしれないが、何かあったときに ID 変更ができないぐらいのケタ数とかアホかとしか思えない。複数カードじゃ追えないというなら、要は、持ち方を統制すればいいという話で先の話につながる。IC チップを体に埋め込んでもエグり出せば同じだから、結局は持ち方の統制の話になる。ならば、今からもうその話をしましょう…と。

国民をトレースというのは、スマホによってゆるやかにすでに実現されている。さらに徹底するなら、GPS なり量子コンパスなり都市ならICカードなりを持ってないなら、職務質問や追跡がありますよ…というぐらいの話だ。

田舎でスマホを持たない者を拘束できる方向を否定しながら、古いシステムを強制する国際組織とか軽蔑せざるを得ないんですが。そこには善意の腐敗か悪意しかない。

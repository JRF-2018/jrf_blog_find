jrf> モンティ・ホール問題と確率操作と生物の話つづき。

生物において３つという数字はなかなか出ないから、４つにする。場合の数が捨てられるのを U で表し、モンティ・ホールの選択 A B C とあわせて、 U A B C の４つを基本として考えることにする。U A B C が変換されていくと考える。U は必ず増加していく、場合の数は棄てられる一方だから。

……。

A がプレイヤーにより最初選ばれるとき、有利な選択は常に司会者が示す B か C となる。このとき、B と C は A に対して優性遺伝のように見えるのかもしれない。A は初手から選ばれないので、A を脱落させることで「司会者」が仕様通りに働くような機構があるように見えるということを想定することになる。このようなものは実際の生物にありうるだろうか？

そのような機構が、有性生殖によって得られたので、有性生殖が有利になったとか言えないか…と妄想する。

BOOK☆WALKER…

BOOK☆WALKER で『道を語り解く』『「シミュレーション仏教」の試み』『神々のための黙示録』を扱ってもらえるようになった。もちろん、まったく売れてない orz。いろいろ労力をかけてもらったので、若干、ギフト機能を使ってお返ししたが、まだ足りないだろう。
JRF 2024年10月22日

『宗教学雑考集』のアーリーアクセス版は BOOTH のみでの販売だが、正式版にするときには、DRM のある他のサイトでも扱ってもらうつもり。Amazon には出品するのは確実だけど、他にも出品できるところはないかと探していた。

『宗教学雑考集 - 易理・始源論・神義論 第0.8版』(JRF 著, ＪＲＦ電版, 2024年1月)
https://j-rockford.booth.pm/items/5358889

JRF 2024年10月22日

そこでまず目を付けたのが、楽天Koboライティングライフ。しかし、楽天は、EPUB の規約が厳しい。URL が含まれていたらダメだというのだ。その辺の経緯は [cocolog:95054550](2024年9月17日) に書いた。

そこで別のところを…と探すと一つは BCCKS、もう一つは BOOK☆WAKER が目についた。ただ BCCKS は有料。この際、有料でも良かったのだが、まずは無料の BOOK☆WALKER にアプローチすることにした。

JRF 2024年10月22日

……。

BOOK☆WALKER では、著者登録に SMS または電話による確認が必要となる。スマホを持っていない私はそこに反感を持つが、今の時代、そうも言ってられないので、母のスマホを借りて、登録を済ませた。

次に問題となったのが、EPUB を登録しようとすると、少しでも EPUB のエラーがあると受け付けてくれないというのがあった。サポートがすでに終了している BOOK☆WALKER の PC 版 EPUB 表示アプリではちゃんと表示できるけれども、細かな規定にひっかかるようでエラーが出る。

JRF 2024年10月22日

ただ、よく調べると、それは私の EPUB ファイルが古いためで、バージョンの上がった Sigil で作り直すと、大きな変更なく、EPUB の登録もできた。

いよいよ審査を待って発売か…。

JRF 2024年10月22日

……。

しかし、審査で問題が発生。楽天でもそうだったが、やはり、URL が含まれているのはいけないらしい。

ただし、楽天と違って、a タグを使った外部リンクはダメだけど、URL のベタ書きなら OK らしい。

ならば、対応できる…と対応して、審査に通った！ そして、発売になった。

JRF 2024年10月22日

その後、楽天のほうにもこの BOOK☆WALKER に通った EPUB ファイルで審査をしてもらった。すると、どうも、楽天も、URL ベタ書きなら通ることがあるようだ。ただし、古い URL のリンクが切れていたらダメらしいので、楽天で出すのはあきらめた。BOOK☆WALKER で出品できれば十分だから。もし、他でも出品したいなら、BCCKS を使うほうが素直で多くのサイトに出品できる(だろうし)。

JRF 2024年10月22日

…… 。

以上がだいたいの経緯だが、それを「グローバル共有メモ」や Twitter (X) に書いたメモの流れからまた辿っていこう。

実は BOOK☆WALKER 様も楽天Koboライティングライフ様と同じく、出版するのに(外部への)ハイパーリンクがダメと言われました。それでいったんは憤ったのですが、しかし、よく読むと URL ベタ書きは許されるとのこと。それであれば、対応できるということで、ハイパーリンクは削られています。

単純にハイパーリンクを削ったもの、削った上で検索用にブログ名を補ったものがあります。が、読んだり検索して確認したりするのに支障はないようになっているはずです。

楽天Koboライティングライフでも、BOOK☆WALKER に提出したのと同じ EPUB で審査が通らないか試してみた。どうも、URL ベタ書きなら楽天も OK なこともあるようだが、今回は、死んでる URL があるかも…と書いたのが引っかかって reject された。

JRF 2024年10月22日

具体的には、「※注意※ 本書に含まれる URL の中にはすでにリンク切れを起こし、当初のものとは違うところ(例えば危険なサイト)に接続するものもあるかもしれませんが、資料性を鑑みそのままにしております。」と書いていた。ただし、実は今度提出した分ではすべて URL (二つだけだし)が生きていることは確認できていた。

JRF 2024年10月22日

とはいえ、今後に出版計画中の別の本では、Internet Archive などで便利なように、古い URL をそのまま記載したいと思っており、古い URL が記載できないということであれば、楽天での出版は諦めたほうがよいと判断し、reject を受け容れた。

JRF 2024年10月22日

懸念もある。仮に出版時に URL が生きていることを確認していたとしても、時間の推移で、URL が死んだとき出版停止にできるということであれば、出版停止を望む本がある場合、わざと URL を殺すすなわちインターネットを破壊するインセンティブを与えることにもなる。古い URL が記載できないのは問題あると思う。

Steam『パラノマサイト FILE 23…

jrf> Steam『パラノマサイト FILE 23 本所七不思議』クリア。6種のエンディングをすべて見た。プレイ時間13.7時間。最後の謎だけ攻略に頼った。そこまで、攻略を見ずに来れたのに悔やしい。

呪詛珠はわかっていたし、意志もまぁわかっていたが、土御門の現身は、こいつか、探偵だとは思っていた。こいつだとするとストーリーの最初のほうだろうといろいろ試してたのだが、ギブアップ。怪しい呪影のことはスッカリ忘れていた。惜しかった。

結局、呪殺ボタンは最初のほうと最後のほうの2度しか押さなかった。最初のは「呪殺」とはわかってないところだし、最後のほうのは、相手がライターを捨ててて発動しなかったし、しかたないところ。それで実績解除とかあるかと思ったがなかった。

おもしろかったと思う。ヒドい(笑)メタネタも最初のほうだけだったし。分岐もほどほどで、やたらあって難しいということもなかった。ある程度、プレイヤーには謎が推測できるというのも、親切で、納得感があった。

こういうのがアリな世の中ならば、PS1『かまいたちの夜 特別篇』 を PS1『メタルギアソリッド』みたいに、そのまま Steam で出してくれないものだろうか。…と思った。

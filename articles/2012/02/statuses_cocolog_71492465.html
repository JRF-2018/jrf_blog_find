ネット対戦に必要なのは「仮ID」「捨てID」ではないか。掲示板などで一時的に仮IDを交換して対戦し、何度かそれを繰り返したあとや実際会ったあと、本ID を教えて FRIEND 登録するというなりゆき。(発想は、「プライバシープロバイダ」や「日銀カード」に少し似てるかな。)
JRF 2012年2月3日

keyword: プライバシー プロバイダ
keyword: 日銀カード

ネット対戦には「内部統制」等で話せない関係(例えば、ニートと企業人とか)がネットごしに表現しあうのに使える。そういったときに「通じさせる表現」をみがくという稽古[けいこ](参：ゲームクラブ [aboutme:130416])ってどういうことになるんだろう？…とか古典芸能に観する本を読みながら([cocolog:71492388])考えた。

そう考えると、仮 ID がないと対戦できない形っだけってのもあまり良くないのかもしれない。それだと SNS みたいにネットに「二階」を作っておしまいになってしまいかねない。

JRF 2012年2月3日

掲示板での「捨て ID」と違い、ゲーム機での対戦は管理会社がしっかりしてるという面がある。ただ、マッチングをコントロールされると企業としてはたまらないし、逆にコントロールできれば好都合だろう。

ゲーム機会社が、そこの信用をどう確立するかというのが、適格和解の非対称性([aboutme:103713])を解消するピースにならないか？

JRF 2012年2月4日

最近、ゲーム会社が [cocolog:71502190] に書いたような携帯電話の SNS の一部としてのゲームに食い込んで行っている。信用の Visualization としてゲーム専用機での仮 ID での親交を seed として携帯ゲームに取り込み、その果実としてライフログ登録権を貨幣化するようなルールってできないものか…？

JRF 2012年2月4日

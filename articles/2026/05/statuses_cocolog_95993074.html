「易双六」自体はすでに Web 版があったのですが、今回のものは、スマホに最適なレトロゲームといったウリになります。

上画面タッチに対応しているのが地味に大きな変更点です。例えば、タイトル画面で上画面領域をタッチするとスタートできます。

ところで、実は YSCHELP には隠し要素としてダンジョンが含まれていました。

最初に表示される「ヨウスコウ マニュアル」のページの「エイゴ (English) マニュアル。」の「。」をクリックすると、なんと「テスト ノ メイキュウ」に行くことができるのです！

ただ、Nintendo DSi や 3DS はすでに「オワコン」となって久しく、誰かにプログラムを見ながらプレイしてほしいという私の願いがもはやどうにもかないそうにないという状況になっていた。

私の希望としては、プチコンmkII のエミュレータが現れて、それでスマホ等でプレイできるようになることを夢見ていた。しかしそれは素材の問題等もあり実現しようがないようだ。新しいプチコンが出るたびに mkII への互換対応なんかも夢見たが、それも実現しなかった。

これで十二分に元は取れたのだが、さらに何か作れる時間的余裕がある…ということで思い付いたのが、「易双六PTC」の Web への移植だった。

JRF 2026年5月16日

……。

しかし、「易双六PTC」は Smile Basic 2 という特殊な BASIC 言語で書かれていて、全然メジャーではない。それを Claude さんが理解できるのかという不安はあった。

実際のところは、その不安は的中しなかった。Claude さんはしっかりプログラム変換をすることができた。

ただ、上の Mapaex と jrf_blog_find のプロジェクトに比べようもないぐらい、私が指示を出す必要があった。

JRF 2026年5月16日

Claude さんの力だけではできなかった。CSS などの問題は ChatGPT や Gemini Pro さんにもかなり手伝ってもらわなければならなかった。私がプログラムを書いたりデバッグしたりして解決したこともあった。

それでもプロジェクト開始から、10日もたたずにデプロイにまで漕ぎ着けたのは、やはり Claude さんがすごかったとしかいいようがない。しかもその間、Claude さんの利用制限…5時間の制限、1週間の制限もあって作業できない時間も長かったのだ。

JRF 2026年5月16日

……。

ただ、やはり 5時間の利用制限は地味に体に良くない。微妙に寝入るには足りない時間だからだ。8時間制限とか10時間制限のほうがいいと思う。もちろん使えない時間も長くなるわけだが、そのほうが人間には合ってる気がする。一部のワーカホリック人間以外。

プチコンmkIIのゲームからの移植。私は当時からうっすらその可能性を視野に入れていたので、プチコンのキャラクタなどをできるだけ使わずに作っていた。だから、二・三キャラクタを置き換えるだけでよかった。プチコンのキャラクタをたくさん使ってるゲームとかはそういう面で移植は難しいと思う。素材面では音楽が私の場合問題となったが、これも完全に置き換えた。

JRF 2026年6月6日

あと、私のは「完全移植」からはほど遠くスプライト処理なんかはかなり実機とは異なる形にするしかなかった。見た目は近くしたけれども、「Smile Basic 2 エミュレータ」的な動作をしている部分は少なく、JavaScript のコードにかなり置き換えて実装している。
